O-SORA v11 GPS TEST

1. GitHub Pagesへこのフォルダの中身をアップロード。
2. Safariで https://あなたのGitHub Pages/gps-test.html を開く。
3. Safariで「位置情報を取得」を押す。
4. 成功することを確認。
5. 同じ gps-test.html を「ホーム画面に追加」して、Open as Web Appで追加。
6. ホーム画面のGPS TESTを起動して同じボタンを押す。
7. 「位置情報の許可がありません（エラー1）」になるか、「GPS取得成功」になるか確認。

このテストページはGAS、Open-Meteo、O-SORA本体の処理を一切使わず、Geolocation APIだけをテストします。
